
# Video Insight AI Assistant

An AI-powered application for exploring video content, asking questions, and retrieving evidence-backed answers.

## Planned Features

- Video transcription
- Video summarization
- Retrieval-Augmented Generation (RAG)
- Hybrid search combining semantic and keyword retrieval
- Reranking relevant passages
- Answers with timestamped citations
- RAG evaluation and retrieval experiments

## Tech Stack

- Python
- Large Language Models (LLMs)
- Vector databases
- Hybrid retrieval
- RAG evaluation

## Project Status

Currently in development.
